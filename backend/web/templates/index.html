关于 Docker2Compose

Docker2Compose (D2C)

v3.2 现代化专业版
核心功能
  • • 自动扫描宿主机 Docker 容器
  • • 依据网络依赖拓扑自动分组
  • • 启动任务与批量 Compose 导出备份
  • • 便捷的配置项与环境变量过滤
快捷提示
  • • 左侧多选容器后一键合并配置
  • • 备份历史支持快速预览与还原
  • • 右侧工作台可即时调整并保存
  • • 支持自定义 CRON 调度策略
